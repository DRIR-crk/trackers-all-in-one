# Trackers All-in-One

A single, deduplicated list of public BitTorrent trackers, merged from several community-maintained sources.
Add it to your torrent client to speed up peer discovery for public torrents.

> **PT-BR:** Uma lista única de trackers públicos de BitTorrent, sem duplicatas, reunida a partir de várias fontes da comunidade. Todo o crédito vai para os mantenedores originais (veja **Credits** abaixo).

## Usage

Direct raw link (paste into your client or script):

```
https://raw.githubusercontent.com/DRIR-crk/trackers-all-in-one/main/trackers_all_in_one.txt
```

- **qBittorrent** → Options → BitTorrent → *Automatically add these trackers to new downloads* → paste the list.
- **Transmission / Deluge / Vuze / BiglyBT** → add trackers to a torrent, one URL per line.

## How it was built

The list is regenerated by [`scripts/update.sh`](scripts/update.sh), run weekly by
[`.github/workflows/update-trackers.yml`](.github/workflows/update-trackers.yml). The script:

1. Downloads each upstream list (see **Credits**) with a browser user-agent, **skipping any source that is temporarily unreachable** so one outage can't break the run.
2. Keeps only valid tracker URLs (`udp://`, `http(s)://`, `ws(s)://`), trims whitespace, and removes duplicates — keeping the first occurrence, so curated/monitored lists stay near the top.
3. Writes `trackers_all_in_one.txt` only if the result clears a minimum count (so an outage never wipes the published list), then refreshes the stats table above and commits any change.
